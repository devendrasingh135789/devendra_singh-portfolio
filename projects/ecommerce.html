Project Summary

Developed a full-stack E-Commerce Website using PHP, MySQL, HTML, CSS, JavaScript and Bootstrap 5. The application provides a complete online shopping experience with separate User and Admin panels. Users can register, login, browse products, search items, manage their shopping cart, place orders, submit reviews and maintain a wishlist. The admin panel enables administrators to manage products, categories, users, orders and customer reviews through a secure dashboard. The project uses MySQL for data storage, PHP Sessions for authentication, and Bootstrap for a fully responsive interface.
